# tools 目录说明

本目录存放与主服务无关的**一次性脚本或辅助工具**，不参与 `app/` 构建或启动流程。

## 当前内容

- **test_pil.py**  
  一次性脚本：用于本地验证 PIL 图像预处理逻辑（缩放、对齐到 64 的倍数、padding 等）。  
  - 运行方式：在仓库根目录或本目录执行 `python3 tools/test_pil.py`。  
  - 会在当前目录生成测试用图片（如 `test_800_600.png`、`test_large.png` 等）并做断言。  
  - 主服务中的图片预处理逻辑在 `app/` 内实现，本脚本仅作开发/调试参考。
